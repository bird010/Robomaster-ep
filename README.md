# Robomaster-ep
## Introduction
This repo contains several scripts for using AI models and GPU power in PC and control the Robomaster.

Connect Robomaster EP through router mode before running the scripts.

## Dependences
1. Yolo v10 for detection:
https://github.com/THU-MIG/yolov10

2. Robomaster SDk for connecting to robomaster EP, fetch the video stream, and control the robot:
https://github.com/dji-sdk/robomaster-sdk
Note that lib/libmedia_codec should also be installed in the Robomaster SDK.
